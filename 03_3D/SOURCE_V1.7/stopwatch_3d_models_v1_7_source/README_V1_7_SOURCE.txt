ESP32 8-channel Wi-Fi Timer enclosure V1.7
=========================================

This package contains the editable OpenSCAD source matching the V1.7 print STL package.

V1.7 changes relative to V1.6:
- rear PG7 reinforcement rail is perforated by all 8 gland openings;
  V1.6 accidentally left a ~1.2 mm membrane behind the holes.
- all V1.6 assembly fixes are retained:
  * button base height 55 mm,
  * lid orientation/mirroring fix,
  * button-base anti-flex ribs clear the lid locating lip,
  * main tray mounting-hole spacing corrected to 63 mm,
  * RESET opening 12.5 mm.

Main enclosure: 160 x 110 x 50 mm.
Button enclosure: 90 x 100 x 55 mm.
Button opening: 24.6 mm.
Current rear gland opening: 12.5 mm.

IMPORTANT NEXT DESIGN ITEM:
The user is considering replacing the 8 rear PG7 glands on the main enclosure with
quick-disconnect panel connectors (GX16 vs M12). Select the exact connector first,
then modify the rear holes and spacing from this source. Do not assume all GX16/M12
panel cutouts are identical.
