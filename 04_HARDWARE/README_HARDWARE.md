# Hardware

Výchozí projekt používá starší referenční obrázky a text v ../05_DOCUMENTATION/07_HARDWARE_AND_WIRING.md. Firmware v ../02_FIRMWARE/SOURCE_v1.3.1/ESP32_Timer_Arduino/ESP32_Timer_Arduino.ino je zdrojem platného mapování GPIO.

[Integrovaná PCB Rev B](PCB_REV_B_INTEGRATED/README.md) je aktuální konstrukční směr: pájený ESP32-WROOM-32E, USB-C programování, nabíjení 18650 s power-path, RTC a osm izolovaných vstupů 12–24 V. **Rev B jsou zatím návrhové podklady, ne výrobní CAD/Gerbery; desku ještě nelze objednat.**

Starší [PCB Rev A](PCB_REV_A/README.md) předpokládala zásuvný 30pin ESP32 DevKit V1 a zůstává archivním zadáním, které Rev B nahrazuje.
